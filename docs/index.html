HandMouse

Webcam hand-gesture control for Windows. One hand. No extra hardware. Fully local.

21hand landmarks / frame
16gestures mapped
~950lines of Python
0bytes sent online

Pipeline

Webcam (OpenCV)→MediaPipe HandLandmarker→Feature extraction→One Euro filter→Gesture state machines→Win32 input→Status widget

Technical analysis

DecisionWhy
Scale-free ratiosDistances divided by hand size. Works near or far from camera.
Hysteresis on pinch (0.30 on / 0.40 off)Stops click flicker at the threshold edge.
Pinch state machineOne thumb+middle signal yields click, right click, drag, scroll by timing.
Hold timers (0.25–0.5 s)Poses passed through mid-motion don't fire. Destructive close needs longest hold.
Lookback bufferForming a fist moves the index. Action targets where cursor was 0.3 s before.
Rule-based finger statesUp/down + thumb out/tucked. Angle-independent, no training data needed.
Knuckle shape matchingCtrl pose detected from palm knuckles only; folding fingers doesn't break it.
Calibrated boxSmall comfortable zone maps to full screen. Less arm fatigue.
Thresholds from recorded takesReal motion replayed through real functions before tuning.
Pure logic + self-test--test asserts gestures without a webcam.

Limits

  • Windows only (Win32 calls).
  • Right hand only; two-hand tracking proved unreliable.
  • Needs decent light. Fatigue on long sessions (gorilla arm).
  • Uses legacy mouse_event; SendInput is the upgrade path.
